Название придумано для этого сайта. Поиск в интернете (31.10.2026) не нашёл компаний, продуктов
или сайтов с таким названием. Но поиск в интернете не заменяет проверку товарных знаков:
**перед продвижением или регистрацией домена проверьте название в реестре ФИПС** (fips.ru →
«Информационные ресурсы» → «Открытые реестры», классы 41 и 44). Если планируете серьёзное
развитие — название можно зарегистрировать как товарный знак.

убран: это олимпийский девиз, а Олимпийская хартия относит его к «олимпийской собственности»
МОК. Для собственного проекта безопаснее свой девиз.

## 5. Безопасность

Уже сделано в коде:

- **Content Security Policy** на каждой странице: браузер выполняет только скрипты и стили
  с самого сайта, картинки — только свои. Внедрённый чужой код (XSS) не запустится;
- **Trusted Types** (`require-trusted-types-for 'script'; trusted-types 'none'`) и код без
  `innerHTML` — опасные способы вставки HTML запрещены браузеру полностью;
- **защита от кликджекинга**: если сайт откроют внутри чужой страницы, вместо содержимого
  появится предупреждение (работает и на GitHub Pages, где нельзя задать заголовки сервера);
- **HTTPS** + `upgrade-insecure-requests`, HSTS, `nosniff`, строгая политика Referrer,
  отключены камера, микрофон и геолокация (в `.htaccess` / `_headers`);
- **ни одного внешнего скрипта, шрифта или счётчика** — нечего взломать «по цепочке поставок»;
- **данные в браузере** (тема, отметки, результаты) проверяются при чтении — испорченные
  значения просто игнорируются;
- **форма**: ограничение длины полей, очистка управляющих символов, кодирование всех данных;
- **`/.well-known/security.txt`** — стандартный файл (RFC 9116), по которому исследователи
  найдут, куда сообщить об уязвимости. Срок действия — до 31.10.2027, потом обновите дату.

Сделайте на стороне хостинга:

1. GitHub Pages: **Settings → Pages → Enforce HTTPS** — поставьте галочку.
2. Сложный пароль и двухфакторная аутентификация на GitHub, хостинге и почте.
3. После переезда на хостинг с заголовками проверьте их: securityheaders.com
   или developer.mozilla.org/observatory.

Если сервер на nginx, добавьте в блок `server { ... }`:

```nginx
add_header Content-Security-Policy "default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self'; manifest-src 'self'; base-uri 'none'; form-action 'self' mailto:; object-src 'none'; worker-src 'self'; frame-ancestors 'none'; upgrade-insecure-requests; require-trusted-types-for 'script'; trusted-types lp-sw" always;
add_header Strict-Transport-Security "max-age=31536000" always;
add_header X-Content-Type-Options "nosniff" always;
add_header X-Frame-Options "DENY" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Permissions-Policy "camera=(), microphone=(), geolocation=(), payment=(), usb=()" always;
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Resource-Policy "same-origin" always;
server_tokens off;
autoindex off;
error_page 404 /404.html;
location ~ /\.(?!well-known) { return 404; }
location ~ ^/(README\.md|_config\.yml|_headers)$ { return 404; }
types { application/manifest+json webmanifest; }
```

## 7. Приложение-тренер (папка `app/`)

**Адрес:** https://artyom1513.github.io/green-pulse/app/ — веб-приложение (PWA): открывается по ссылке,
устанавливается на главный экран телефона и работает без интернета.

**Главная фишка — «тренер, который слушает тело»:**

- объёмная 3D-модель человека (WebGL, без сторонних библиотек): плавные руки и ноги, кисти
  с пальцами, стопы, рельеф груди, лопаток, ягодиц и икр, черты лица; 37 зон с правой и левой
  стороной — от трапеции и ключицы до подколенной области, пятки и пальцев стопы; вращение,
  масштаб, виды спереди, сзади и сбоку; касание выбирает зону, а режим «Обвести» позволяет обвести
  пальцем больное место и описать проблему — силу боли (0–10), симптомы, когда началось и что
  усиливает; опасные упражнения исключаются, а приложение объясняет, что и почему убрано;
  в браузерах без WebGL показывается простая карта;
- дневник боли с линией динамики по каждой зоне и подсказкой учесть сильную боль в тренировках;
- справочник травм: 20 статей (растяжения, спина, колено, плечо, ахилл, сотрясение, крепатура,
  как начать с весами и другие) — первая помощь, тревожные признаки, когда к врачу и как вернуться
  к нагрузке; пересказ открытых рекомендаций ВОЗ, NHS, NICE, ACSM и консенсусов спортивной медицины
  со ссылками на источники;
- тренировки с весами: гантели, гиря и штанга, цели «Сила» и «Мышцы» с подходами и отдыхом;
  в плеере записываются вес и повторы каждого подхода, приложение подсказывает, когда прибавить
  вес (двойная прогрессия), отмечает личные рекорды по расчётному 1ПМ и рисует график роста;
- схемы движений для всех 193 упражнений: анимированный человечек (SVG, без видео и внешних
  файлов) в карточке упражнения и в плеере; при «уменьшении движения» в системе — статичная поза;
- карта восстановления мышц: по упражнениям за последние 72 часа приложение оценивает нагрузку
  на группы мышц, показывает её на 3D-модели и ставит в план отдохнувшие мышцы;
- кнопка «Заменить» в плеере: похожие упражнения на выбор, если нет инвентаря или не нравится;
- 5 челленджей на 30 дней (приседания, планка, отжимания, гибкость, ходьба) и утренняя зарядка,
  которая меняется каждый день; два кольца недели — норма ВОЗ и тренировки по плану;
- отчёт для врача (зоны, дневник боли, сигналы боли, нагрузка за 14/30/90 дней — печать, PDF
  или текст), калькуляторы (ИМТ, калории, белок и вода, пульсовые зоны, 1ПМ) и дневник веса тела;
- защита от потери данных: напоминание о резервной копии раз в месяц, запрос постоянного
  хранилища у браузера, выгрузка тренировок, подходов, дневника боли и веса в CSV;
- 8 программ: 5 восстановительных (колени, спина, голеностоп, плечи, связки) и 3 силовые
  («Сила без железа», «Гантели с нуля», «Гиря: базовый курс»);
- конструктор: свои тренировки из любых упражнений с кругами и отдыхом — с той же проверкой безопасности;
- кнопка «Больно» во время тренировки: упражнение сразу заменяется безопасным, зона бережётся 7 дней;
- отметка самочувствия: по сну, энергии, мышцам и стрессу выбирается интенсивность дня;
- прогрессия: по оценке тяжести (1–10) нагрузка плавно растёт или снижается;
- анкета безопасности при первом запуске включает бережный режим, если есть риски.

**Безопасность приложения:**

- данные хранятся только на устройстве; серверов, аналитики, рекламы и cookie нет;
- по желанию — пароль: все данные шифруются AES-GCM 256 бит, ключ — PBKDF2-SHA-256, 600 000 итераций;
  ключ живёт только в памяти, автоблокировка через 5 минут в фоне, ограничение попыток ввода пароля;
- строгая политика безопасности (CSP) и Trusted Types: единственное исключение — именованная политика
  `lp-sw`, которая пропускает только адрес `./sw.js` для офлайн-режима;
- всё, что загружается из памяти браузера или из файла копии, проходит проверку по схеме
  (типы, длины, списки допустимых значений), поэтому подменённые данные не сломают приложение
  и не выполнят чужой код;
- защита от встраивания в чужие страницы, никакого `innerHTML`, внешних скриптов и шрифтов.

Честно о пределах: «невзламываемых» программ не бывает. Главный оставшийся риск — доступ к
разблокированному телефону; от него защищает пароль. Сайт и приложение живут на общем адресе
`artyom1513.github.io` вместе с другими вашими проектами на GitHub Pages: у них общая память
браузера, поэтому для приложения с данными о здоровье полезно включить пароль, а при развитии
проекта — перенести его на собственный домен.

и не используйте слова «лучший», «№ 1» без подтверждения. Приложение не является медицинским изделием: оно не ставит диагнозов и только исключает
упражнения по отметкам, которые пользователь делает сам. Перед коммерческим использованием покажите
приложение юристу.

**Как выпускать обновления:** после любых изменений в `app/` увеличьте номер версии в строке
`const VERSION = "lpapp-1.4.0"` в файле `app/sw.js` (и `VERSION` в `app/app.js`) — иначе телефоны
с установленным приложением будут показывать старую версию из кэша.

**Поисковики и соцсети:** ссылки на картинку для соцсетей и канонические адреса в `index.html`
и `app/index.html` указаны для `artyom1513.github.io/green-pulse` — при переезде на свой домен
замените адрес. Файл `robots.txt` работает только в корне домена, поэтому для проекта на
`github.io/green-pulse` его не добавить; добавьте `sitemap.xml` вручную в Яндекс Вебмастер и Google
Search Console. На своём домене положите `robots.txt` со строкой `Sitemap:`.

## 8. GitHub Pages и другой хостинг

**GitHub Pages** (сейчас): Settings → Pages → *Deploy from a branch* → `main` / `(root)` → Save.
После каждого коммита в `main` сайт обновляется сам. Файл `_config.yml` нужен только здесь.

**Свой домен или другой хостинг:** загрузите всё, кроме `README.md` и `_config.yml`.
`.htaccess` нужен для Apache, `_headers` — для Netlify и Cloudflare Pages. В `404.html` замените
путь `/green-pulse/` на `/`.

**На телефоне** не открывайте скачанный `index.html` из архива: мобильные браузеры не подгружают
соседние файлы (стили, скрипты, картинки), и страница выглядит почти пустой. Открывайте сайт
по ссылке.
