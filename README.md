# Листопульс — памятка владельца сайта

Сайт о питании, движении, сне и привычках: 14 статей, 14 калькуляторов и практик, тест
«Миф или факт», трекер привычек и вызов дня. Чистые HTML, CSS и JavaScript, без внешних
библиотек, шрифтов и счётчиков.

**Адрес на GitHub Pages:** https://artyom1513.github.io/green-pulse/

персональные данные граждан РФ на серверах в России (ч. 5 ст. 18 152-ФЗ). Включите в почте
двухфакторную аутентификацию — это обещано в политике конфиденциальности.

## 2. Название «Листопульс»

Название придумано для этого сайта. Поиск в интернете (31.10.2026) не нашёл компаний, продуктов
или сайтов с таким названием. Но поиск в интернете не заменяет проверку товарных знаков:
**перед продвижением или регистрацией домена проверьте название в реестре ФИПС** (fips.ru →
«Информационные ресурсы» → «Открытые реестры», классы 41 и 44). Если планируете серьёзное
развитие — название можно зарегистрировать как товарный знак.

Девиз «Маленькие привычки. Большая энергия.» тоже свой. Прежний девиз «Быстрее. Выше. Сильнее.»
убран: это олимпийский девиз, а Олимпийская хартия относит его к «олимпийской собственности»
МОК. Для собственного проекта безопаснее свой девиз.

## 3. Авторские права

- **Тексты** всех статей написаны своими словами; данные ВОЗ, NHS и научных работ пересказаны
  со ссылками на первоисточники.
- **Иллюстрации, логотип и иконки** нарисованы специально для сайта (SVG-файлы в `img/`).
  Фотографии с фотостоков удалены: больше нет вопросов к лицензиям и к праву людей на
  собственное изображение (ст. 152.1 ГК РФ).
- **Шрифты** не загружаются: используются системные шрифты устройства посетителя.
- Новые картинки берите только свои или с явной лицензией на коммерческое использование.
  Изображения из поиска Google/Яндекс использовать нельзя.

## 4. Персональные данные (152-ФЗ)

Форма обратной связи собирает имя и e-mail, поэтому владелец сайта считается оператором
персональных данных. На сайте уже есть всё нужное:

- политика обработки данных — `privacy.html` (в ней указан хостинг GitHub Pages — при переезде
  поменяйте пункт 2.4);
- отдельный документ согласия — `consent.html` (с 1 сентября 2025 года согласие оформляется
  отдельно от других документов);
- обязательная галочка согласия в форме, по умолчанию не отмеченная.

Что можете сделать только вы:

- **подать уведомление в Роскомнадзор** до начала сбора данных: pd.rkn.gov.ru (бесплатно, онлайн);
- для постоянной работы выбрать **хостинг с серверами в России**: GitHub Pages удобен, чтобы
  показать сайт, но его серверы находятся в США;
- не подключать Google Analytics, Яндекс Метрику, виджеты соцсетей и т. п. без обновления политики
  (сейчас сайт не использует cookie и сторонние скрипты, поэтому баннер про cookie не нужен).

Прочее: медицинская оговорка — в подвале и на `legal.html`; возрастная маркировка 12+ (436-ФЗ) —
в подвале; рекламы нет. Если появятся реклама, продажи или платные услуги, понадобятся маркировка
рекламы, оферта и т. п. — тогда стоит показать сайт юристу. Эта памятка не заменяет юридическую
консультацию.

## 5. Безопасность

Уже сделано в коде:

- **Content Security Policy** на каждой странице: браузер выполняет только скрипты и стили
  с самого сайта, картинки — только свои. Внедрённый чужой код (XSS) не запустится;
- **Trusted Types** (`require-trusted-types-for 'script'; trusted-types 'none'`) и код без
  `innerHTML` — опасные способы вставки HTML запрещены браузеру полностью;
- **защита от кликджекинга**: если сайт откроют внутри чужой страницы, вместо содержимого
  появится предупреждение (работает и на GitHub Pages, где нельзя задать заголовки сервера);
- **HTTPS** + `upgrade-insecure-requests`, HSTS, `nosniff`, строгая политика Referrer,
  отключены камера, микрофон и геолокация (в `.htaccess` / `_headers`);
- **ни одного внешнего скрипта, шрифта или счётчика** — нечего взломать «по цепочке поставок»;
- **данные в браузере** (тема, отметки, результаты) проверяются при чтении — испорченные
  значения просто игнорируются;
- **форма**: ограничение длины полей, очистка управляющих символов, кодирование всех данных;
- **`/.well-known/security.txt`** — стандартный файл (RFC 9116), по которому исследователи
  найдут, куда сообщить об уязвимости. Срок действия — до 31.10.2027, потом обновите дату.

Сделайте на стороне хостинга:

1. GitHub Pages: **Settings → Pages → Enforce HTTPS** — поставьте галочку.
2. Сложный пароль и двухфакторная аутентификация на GitHub, хостинге и почте.
3. После переезда на хостинг с заголовками проверьте их: securityheaders.com
   или developer.mozilla.org/observatory.

Если сервер на nginx, добавьте в блок `server { ... }`:

```nginx
add_header Content-Security-Policy "default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self'; manifest-src 'self'; base-uri 'none'; form-action 'self' mailto:; object-src 'none'; frame-ancestors 'none'; upgrade-insecure-requests; require-trusted-types-for 'script'; trusted-types 'none'" always;
add_header Strict-Transport-Security "max-age=31536000" always;
add_header X-Content-Type-Options "nosniff" always;
add_header X-Frame-Options "DENY" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Permissions-Policy "camera=(), microphone=(), geolocation=(), payment=(), usb=()" always;
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Resource-Policy "same-origin" always;
server_tokens off;
autoindex off;
error_page 404 /404.html;
location ~ /\.(?!well-known) { return 404; }
location ~ ^/(README\.md|_config\.yml|_headers)$ { return 404; }
types { application/manifest+json webmanifest; }
```

## 7. GitHub Pages и другой хостинг

**GitHub Pages** (сейчас): Settings → Pages → *Deploy from a branch* → `main` / `(root)` → Save.
После каждого коммита в `main` сайт обновляется сам. Файл `_config.yml` нужен только здесь.

**Свой домен или другой хостинг:** загрузите всё, кроме `README.md` и `_config.yml`.
`.htaccess` нужен для Apache, `_headers` — для Netlify и Cloudflare Pages. В `404.html` замените
путь `/green-pulse/` на `/`.

**На телефоне** не открывайте скачанный `index.html` из архива: мобильные браузеры не подгружают
соседние файлы (стили, скрипты, картинки), и страница выглядит почти пустой. Открывайте сайт
по ссылке.
